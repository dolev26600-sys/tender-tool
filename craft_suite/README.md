# יומן עסק — MVP לבעלי מקצוע

כלי הצעות מחיר, יומן עבודות וגבייה לחשמלאים, אינסטלטורים, שיפוצניקים
ובעלי מקצוע דומים. נבנה כמוצר נפרד מ-tender-tool, לבדיקת ביקוש מהירה
לפני השקעה בבנייה מלאה.

## למה זה קיים

מחקר שוק העלה שכלים כמו פיקס (Fiix) כבר פותרים את שלב "הצעת המחיר"
בישראל, אבל אף אחד לא בנה בעברית את מה שקורה **אחרי** ההצעה — יומן,
תיאום תורים וגבייה — בדיוק מה ש-Jobber ו-Housecall Pro מוכרים כחבילה
אחת בחו"ל. זה הבידול: לא תחרות על "הצעת מחיר חכמה", אלא על מה שסביבה.

## מבנה

```
craft_suite/
├── quote_agent.py   # קלט: תיאור עבודה חופשי -> פלט: הצעת מחיר מובנית (Claude)
├── storage.py        # אחסון JSON פשוט ללקוחות/עבודות (data/, נוצר אוטומטית)
├── ui.py              # עיצוב Streamlit משותף (RTL, כותרת)
├── app.py             # 3 טאבים: הצעת מחיר חדשה / יומן עבודות / לקוחות וגבייה
└── requirements.txt
```

## הרצה

```bash
cd craft_suite
pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-..."
streamlit run app.py
```

## מה זה עדיין לא

- בלי גביית תשלום אמיתית (רק מעקב סטטוס "שולם" ידני) - שלב הבא אחרי
  שיש ביקוש: אינטגרציית סליקה/ביט, ואז עמלת גבייה כמקור הכנסה שני.
- בלי שליחת הצעה/תזכורות אוטומטית ללקוח (וואטסאפ/SMS) - מועמד ראשון
  לפיצ'ר הבא אחרי שהזרימה הבסיסית מאומתת עם 3-5 בעלי מקצוע אמיתיים.
- אחסון JSON מקומי בלבד, לא רב-משתמשים - מספיק לבדיקת ביקוש, לא למכירה.
